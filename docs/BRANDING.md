# MWTSI branding — v2.2.0

MWTSI Address Intelligence remains the wordmark. The character avatar, its runtime PNG and the fixed decorative background are removed. Shared Brand uses the wordmark with OrbitGlobe, a local SVG globe motif with wireframe, moving land, route signals and an orbiting point. public/branding/mwtsi-mark.svg supplies the abstract M browser icon. No external imagery or customer location service is used.

The workspace globe animates subject to the browser-local pause choice, reduced-motion setting and tab visibility. Login/password and administration remain static. Mobile keeps the wordmark and labelled navigation. See UI_REFRESH_v2.2.md and UI_ASSESSMENT_v2.2.md. Versioned source archives before this release retain their original immutable assets for signed patch validation; this does not put the character into the current app.


## v3.1 color schemes

The MWTSI wordmark and animated OrbitGlobe adopt the current account color scheme in Dark or Light mode. No character artwork returns. The globe still respects reduced motion and the pause control. The default remains Aurora dark; see APPEARANCE_v3.1.md.
