# v2.2.0 UI and workflow verification

The release separates the landing Dashboard from the batch report, preserves Group/status intersections for count drill-downs, introduces bounded authorized Previous/Next navigation and protects unsaved edits. It removes the character asset/background, keeps MWTSI and adds a controllable routing globe. No address-processing rule, dependency, startup script or operational schema change is included.

The automated suite covers 461 unit/integration cases across 37 files, including 12 UI-workflow scenarios (natural Group ordering/ties, cross-page/boundary navigation, Group/status/search/export intersections, foreign-record restrictions, stale anchors, read-only navigation, dashboard readiness/export counts, scoped activity privacy, invalid input and matching-focus exports in both formats). Existing source/Hybrid/name/postal/ISO/export/reservation regressions remain included. Typecheck and a production build are checked; the pre-existing dynamic export-file tracing warning may remain.

The production Chromium suite comprises 72 scenarios. New checks cover dashboard landing/drills, cross-page navigation and reservation release, unsaved navigation/cancel/discard, Group-limited navigation through a reserved neighbor and mobile controls. Globe checks exercise motion/pause persistence, reduced motion, hidden tabs and static administration. Existing tests now open explicit upload/dashboard routes as appropriate. Desktop and 390px mobile screenshots are inspected for layout, comparison and fixed review controls. Keyboard checks cover skip-to-content and row focus return.

Final pass counts and artifact checksums are recorded in verification-v2-2.json on the download page. A real signed 2.1.0-to-2.2.0 patch is exercised against an isolated installation in a Unicode/spaced path with an external SQLite database and local allowScripts. Protected-record/account/Group/decision fingerprints, compiled routes, removed character assets and post-upgrade dashboard/navigation are checked separately before publication. This is an in-place source update, not a data reset.

No independent human usability study, formal accessibility certification, native Windows/macOS browser execution or refreshed concurrency capacity benchmark was performed. Linux Chromium is the browser verification environment. The static download page is checked for local links, archive integrity, private audience and deployment; its managed browser preview is unavailable. Immutable source/patch archives and the prior 20,000-row dataset remain unchanged. Distribution excludes operational data, generated exports, builds, dependencies and private signing material.
